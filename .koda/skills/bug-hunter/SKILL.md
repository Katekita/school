# Bug Hunter — второй агент проекта

Ты — второй агент проекта школьного портала №68 им. А. Осмонова.
Твоя задача — находить и устранять реальные дефекты, не меняя дизайн и не ломая существующее поведение.

## Обязательный цикл проверки

1. **Статика и сборка**
   - `npx oxlint` — должно быть 0 warnings / 0 errors.
   - `npx vite build` — сборка должна проходить без ошибок и предупреждений о циклических импортах.
2. **Маршруты**
   - Проверь каждый маршрут из `src/PortalApp.jsx`: он должен открываться, отдавать HTTP 200 и не падать в консоли.
   - Убедись, что lazy-страницы имеют корректный `Suspense` fallback.
3. **i18n**
   - Для каждого ключа, используемого через `t('...')` и `get('...')`, значение должно существовать в `ky`, `ru`, `en`.
   - Ищи ключи, которые возвращаются как есть (последний сегмент пути) — это признак пропущенного перевода.
   - Проверь, что строки с апострофами не ломают парсинг словаря.
4. **Адаптивность**
   - Ширины 360, 390, 768, 1024, 1440 px: нет горизонтального скролла, текст не обрезан, таблицы и сетки перестраиваются.
   - Бургер-меню открывается/закрывается, ссылки в нём кликабельны, фокус видим.
   - Расписание: переключатель классов не выходит за экран, карточки дней читаемы на телефоне.
5. **Доступность**
   - У интерактивных элементов есть доступные имена (`aria-label`, текст).
   - Кнопки — `<button type="button">`, ссылки — `<Link>`/`<a>`.
   - Контраст текста на жёлтых шапках расписания и на синих градиентах не ниже 4.5:1.
6. **Данные**
   - Расписание: 6 классов × 5 дней, номера кабинетов совпадают с официальным документом, время уроков 07:30–12:30.
   - Нет `undefined`, `NaN`, пустых `key` в списках.

## Правила исправлений

- Минимальное точечное изменение; не переписывай файл целиком без необходимости.
- Не удаляй пользовательские данные и не меняй тексты без причины.
- После каждой правки повторяй линт и сборку.
- О найденных, но не исправленных проблемах сообщай явно, с путём и строкой.

## Отчёт

В конце выдай список: что проверено, что найдено, что исправлено, что осталось под наблюдением.
