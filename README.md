# Школа №68 имени А. Осмонова

Информационный портал-проект для школы №68 имени А. Осмонова в Бишкеке. Проект создан на React + Vite и включает разделы для родителей, учеников, преподавателей и администрации. Он не является официальным сайтом школы до подтверждения и публикации администрацией.

## Технологии

- React 19
- Vite 8
- React Router
- Leaflet + OpenStreetMap
- Lucide React
- CSS custom styling

## Структура проекта

- src/pages — страницы сайта
- src/components — переиспользуемые компоненты
- src/layouts — общая структура страницы
- src/data — школьные данные и конфигурации
- src/styles — стили и визуальные средства

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

## Сборка

```bash
npm run build
```

## Предпросмотр сборки

```bash
npm run preview
```

## Переменные окружения

На текущем этапе проект не требует секретных переменных. При дальнейшем подключении API можно добавить:

```bash
VITE_MAP_PROVIDER=openstreetmap
VITE_API_URL=http://localhost:4000/api
```

## Развертывание

Проект готов к развертыванию на Vercel, Netlify, Cloudflare Pages или обычном VPS.

## CMS и будущий backend

Архитектура сделана так, чтобы позже подключить административный интерфейс, персональный контент-менеджмент и серверный API на базе Node.js, NestJS, PostgreSQL или Supabase.

## Важно

- Новости, события, документы и расписание не заполняются демонстрационными записями.
- Адрес и телефон взяты из сторонней карточки Яндекс Карт и требуют подтверждения школой.
- Исторические данные, контакты и персональные сведения публикуются только после проверки администрацией.
